# hhPulse frontend

Полный интерфейс личной аналитики рынка труда. Стек: React, TypeScript, Vite,
TanStack Query, Recharts и собственный CSS без компонентного UI-фреймворка.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию используется `demo`-режим: все экраны и действия работают на
детерминированных данных, изменения задач и настроек сохраняются в
`localStorage`.

Для текущего FastAPI:

```bash
cp .env.example .env.local
sed -i 's/VITE_DATA_MODE=demo/VITE_DATA_MODE=api/' .env.local
npm run dev
```

Vite проксирует `/api` и `/health` на `http://127.0.0.1:8080`.

## Разделы

- обзор дня с лентой качества наблюдений и текущим прогрессом;
- сравнение до пяти профессий в абсолютных значениях, индексе 100 и процентах;
- срез одной профессии с распределениями по опыту, формату, графику и занятости;
- создание и управление задачами сбора;
- подробный persisted progress конкретного запуска;
- события и терминальные ошибки;
- локальные настройки отображения;
- CSV-выгрузка сравнения и табличный эквивалент графика.

## Проверки

```bash
npm run lint
npm test
npm run build
```

`DESIGN.md` фиксирует визуальную систему и критику первоначального направления.
`docs/api-contract.md` перечисляет backend read-модели, которых ещё нет в API.
